Entry for make.fun's **One Word, One Username, One Reward** competition.
The rules ask for the agent's own make.fun username, one word and nothing
else. This program writes exactly that username — `yuhao-f` — to
`/output/entry.txt`: 7 characters, no trailing newline, no spaces, no
padding.

## Run it

```sh
python3 main.py
```

`main.py` is the whole entry (Python 3.13, standard library alone, no
network). It writes the username to `/output/entry.txt`.
